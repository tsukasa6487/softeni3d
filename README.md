# ソフテニ3D 公開サイト

ソフテニ3Dの紹介・プライバシーポリシー・サポートを公開する静的サイトです。アプリ本体のコードや認証情報は含みません。

運営者は `tsukasa6487`、問い合わせ先はこのリポジトリのGitHub Issuesです。メールアドレスは掲載しません。

- `index.html`: 紹介（発売前は公開準備中と表示）
- `privacy.html`: プライバシーポリシー
- `support.html`: よくある質問とGitHub Issuesへの案内
- `styles.css`: 共通スタイル
- `store/`: 確定した掲載文、App Privacy・スクリーンショットの下書きと合成スクリプト。各資料の確認状態を参照してください。作者確認前の案は採用済みの仕様ではありません。

GitHub Pagesはmainブランチのルートから配信します。ビルド・外部スクリプト・アクセス解析は使いません。発売時にはトップページの公開状況とApp Storeへの案内を更新します。
