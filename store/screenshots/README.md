# スクリーンショットの撮影手順

- 状態: 採用。5枚の画像は作者が確認済み（2026-10-29）。
- 最終更新: 2026-10-29



アプリのWeb版をiPhoneの大きさ（393×852の3倍）で撮り、見出しを付けて、必須枠のDynamic Island・medium用の1179×2556（RGB、透過なし）を5枚作る。撮影から合成までは、アプリ本体のリポジトリの `scripts/promo/store.mjs` で行い、採用した画像は同じリポジトリの `assets/store/screenshots/` に置く。画面を変えたら作り直す。

見た目は告知動画に揃える。暗いグラデーションの背景、2行の大きな見出し（大事な言葉はアプリの球の軌道と同じ黄色）、角の丸いスマホの枠。検索結果では最初の数枚しか見えないため、1枚目だけはスマホの枠を使わず、全画面の3Dを画像いっぱいに使う。ホーム画面は使わない。

保存した戦術は、テンプレート1「後衛サーブ・後衛レシーブ（クロス）」を写した「クロスの展開」（ステップ1=サーブ、2=赤後衛の移動、3=クロス返球。ステップ3の一言メモは「クロスへ返してラリーをつなぐ」）と、前衛のポーチで終わる「クロスの打ち合いから前衛ポーチ」、ほかのテンプレートを写した3件。名前に個人名を使わない。

|番号|見出し（黄色にする言葉）|画面|戦術・視点・状態|
|---|---|---|---|
|01|動きを作って、／伝える（伝える）|全画面（画像いっぱい）|クロスの展開、斜め視点。ステップ3の返球が飛んでいる途中で、メモの字幕が出て、操作ボタンが隠れた状態|
|02|配球と移動を、／1つずつ（1つずつ）|作成|クロスの展開を閲覧から編集。真上、ステップ3まで、作りかけなし|
|03|選手の目線で、／確かめる（選手の目線）|閲覧|クロスの展開、青後衛の選手視点。ステップ3の返球が向かってくる途中|
|04|全画面で、／大きく見せる（大きく）|全画面|クロスの打ち合いから前衛ポーチ、指2本で少しズームした斜め視点。ボレーの瞬間で、操作ボタンが隠れた状態|
|05|戦術を残して、／渡せる（渡せる）|保存一覧|上の5件|

Appleの2026-10-25の案内ではDynamic Island・mediumが必須。最終アップロード時も必要枠をASC画面で照合する。対応寸法は [Appleの仕様](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) を提出時にも確認する。
スクリーンショットの見た目を実機での動作確認として扱わない。
課金商品の審査用画像には、RCの実機で撮った無料状態の購入画面を、加工せずに使う。Appleアカウントや個人情報は写さない。
