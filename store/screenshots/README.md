# スクリーンショットの撮影案

- 状態: 作者確認前の下書き。ストアに公開する確定文ではありません。
- 最終更新: 2026-10-25



下表は撮影案。作者が確認する。最終RCのTestFlightで撮り、オリジナルPNGを縮小せず渡す。個人の通知がない状態にし、バージョン・ビルド・機種・iOS版と一緒に記録する。
同じ戦術を使うため、テンプレート1「後衛サーブ・後衛レシーブ（クロス）」を「この続きを作る」でコピーし、「クロスの展開」という名前で保存する。ステップ1=サーブ、2=赤後衛の移動、3=クロス返球。ステップ3の一言メモを「クロスへ返してラリーをつなぐ」にする。

|番号・見出し案|画面|戦術・ステップ・視点・停止状態|
|---|---|---|
|01 動きを作って、伝える|ホーム|起動演出が終わった斜めコート、ダイアログなし|
|02 配球と移動を、1つずつ|作成|クロスの展開、ステップ3確定後、真上、作りかけなし|
|03 選手の目線で、確かめる|閲覧|クロスの展開、ステップ3、青後衛の選手視点で停止。別途同ステップの斜め視点・メモ表示も予備で撮影|
|04 横向きで、大きく見せる|全画面|クロスの展開、ステップ3、斜め視点、横向き、ボール飛行中の操作ボタンが隠れた状態（タイミングが難しければ停止・ボタン表示でよい）|
|05 戦術を残して、渡せる|保存一覧|クロスの展開を含む自作の3件、個人名なし。「…」の書き出しを含むメニューを開く。OSの共有先一覧は写さない|

合成: [compose-store-screenshot.ps1](./compose-store-screenshot.ps1)。
1320×2868の縦キャンバスに見出しと枠を配置し、素材は縦横比を保って収め、切り取らない。横素材も縦キャンバス内にそのまま収める。
6.9インチ枠の対応寸法は [Appleの仕様](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) を提出時にも確認する。
スクリーンショットの見た目を別機種の実機動作確認として扱わない。
実機の購入画面（設定または無料上限）も審査用の予備素材として撮影し、既存のWeb画像を置き換える場合は課金商品の審査用画像へ使う。
